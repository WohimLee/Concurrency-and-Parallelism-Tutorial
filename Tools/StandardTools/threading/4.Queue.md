`queue.Queue` 可以说是 Python 多线程编程里**最重要的生产级工具之一**。

很多情况下：

```text
Thread + Queue
```

就已经能解决 80% 的多线程需求了。

甚至很多项目里：

```text
不用 Lock
不用 Event
不用 Condition
```

只用：

```text
Queue
```

---

# 1. Queue 是干什么的

一句话：

> 线程安全的任务传递通道。

例如：

```text
生产者线程
      ↓
    Queue
      ↓
消费者线程
```

```text
Producer
   ↓
 Queue
   ↓
Consumer
```

---

现实例子：

```text
下载线程
      ↓
 Queue
      ↓
保存线程
```

或者：

```text
爬虫线程
      ↓
 Queue
      ↓
解析线程
```

---

# 2. 为什么不用 list

很多人会写：

```python
tasks = []
```

生产者：

```python
tasks.append(task)
```

消费者：

```python
task = tasks.pop(0)
```

问题：

多个线程同时操作：

```text
append
pop
```

可能发生竞态条件。

你需要：

```python
lock.acquire()
...
lock.release()
```

自己处理同步。

---

而 Queue 已经帮你做好了：

```text
Lock
Condition
等待机制
唤醒机制
```

全部内置。

q.get()  # 1

# 6. Queue 最强大的地方

## 自动阻塞

假设队列为空：

```python
q.get()
```

不会报错。

不会返回 None。

而是：

```text
等待
```

直到有新任务。

---

例如：

```python
def worker():

    while True:

        task = q.get()

        print(task)
```

启动后：

```text
等待任务
```

主线程：

```python
q.put("hello")
```

worker 立即醒来：

```text
hello
```

---

这就是生产者消费者模型。

# 7. 完整生产者消费者

```python
from queue import Queue
import threading

q = Queue()
```

消费者：

```python
def worker():

    while True:

        task = q.get()

        print("处理:", task)

        q.task_done()
```

---

启动消费者：

```python
threading.Thread(
    target=worker,
    daemon=True
).start()
```

---

生产任务：

```python
for i in range(10):
    q.put(i)
```

输出：

```text
处理: 0
处理: 1
处理: 2
...
```

# 8. task_done()

很多人第一次学都会忽略。

```python
q.task_done()
```

作用：

告诉 Queue：

```text
这个任务已经完成
```

例如：

```python
task = q.get()

process(task)

q.task_done()
```

---

如果不调用：

Queue 会认为：

```text
任务还没完成
```

---

# 9. join()

等待所有任务完成。

```python
q.join()
```

例如：

```python
for i in range(100):
    q.put(i)

q.join()

print("全部完成")
```

意思：

```text
等待100个任务全部 task_done()
```

---

流程：

```text
put()
 ↓
未完成任务数 +1

task_done()
 ↓
未完成任务数 -1

归零
 ↓
join()返回
```

---

这是 Queue 最常见写法：

```python
for item in data:
    q.put(item)

q.join()
```

# 11. maxsize

限制队列大小。

```python

```

最多：

```text
5个元素
```

---

例如：

```python

    q.put(i)
```

前5个：

```text

```

第6个：

```text

```

直到有人消费。

---

这叫：

> Back Pressure（背压）

防止生产速度远快于消费速度。

# 15. 优雅停止 Worker

真实项目最常见问题：

```python
while True:
    task = q.get()
```

永远不会退出。

---

解决方案：

放一个特殊对象。

叫：

> Sentinel（哨兵对象）

---

例如：

```python
STOP = object()
```

worker：

```python
while True:

    task = q.get()

    if task is STOP:
        break

    process(task)

    q.task_done()
```

---

停止：

```python
q.put(STOP)
```

线程结束。

---

这是工业界最常见模式。

# 18. Queue 的三种类型

### Queue

普通 FIFO

```python
from queue import Queue
```

```text
1

3
```

取出：

```text
1

```

---

### LifoQueue

栈

```python
from queue import LifoQueue
```

```text
1
2
3
```

取出：

```text
3
2

```

---

### PriorityQueue

优先级队列

```python
from queue import PriorityQueue
```

放入：

```python
q.put((2, "taskB"))
q.put((1, "taskA"))

```

取出：

```text
taskA
taskB
taskC
```

按优先级排序。

# 19. 实际项目中的经典模板

这是最值得背下来的版本：

```python
from queue import Queue
import threading

q = Queue()

def worker():

    while True:

        task = q.get()

        try:
            process(task)

        finally:
            q.task_done()

for _ in range(4):
    threading.Thread(
        target=worker,
        daemon=True
    ).start()

for item in tasks:
    q.put(item)

q.join()

print("全部完成")
```

这个模板可以直接用于：

* 爬虫
* 文件处理
* 图片处理
* 日志系统
* ETL
* 批量 API 调用

## Queue 最核心的理解

不要把它当成“高级列表”。

把它当成：

```text
线程安全的任务传送带
```

```text
Producer
    ↓
  Queue
    ↓
Consumer
```

它内部已经帮你处理了：

* 加锁（Lock）
* 等待（Condition）
* 唤醒（notify）
* 任务计数（join/task_done）

所以在多线程项目里，经常会看到一句经验：

> 能用 Queue 传递数据，就尽量不要共享数据；能不共享数据，就尽量不用 Lock。
