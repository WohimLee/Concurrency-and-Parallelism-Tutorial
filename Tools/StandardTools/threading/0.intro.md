`threading` 最重要掌握这几块：

### 1. Thread：创建和启动线程

```python
import threading

def work(name):
    print(f"hello {name}")

t = threading.Thread(target=work, args=("Alice",))
t.start()
t.join()
```

核心方法：

```python
t.start()   # 启动线程
t.join()    # 等线程结束
t.is_alive()
```

---

### 2. GIL：Python 线程不适合 CPU 密集任务

在 CPython 里，`threading` 更适合：

```text
I/O 密集：网络请求、文件读写、等待数据库
```

不太适合：

```text
CPU 密集：大量计算、图像处理、压缩、加密
```

CPU 密集通常用：

```python
multiprocessing
concurrent.futures.ProcessPoolExecutor
```

---

### 3. Lock：保护共享数据

多个线程同时改同一个变量，可能出错。

```python
lock = threading.Lock()
count = 0

def add():
    global count
    for _ in range(100000):
        with lock:
            count += 1
```

重点记住：

```python
with lock:
    # 临界区
```

---

### 4. RLock：可重入锁

同一个线程可以重复拿锁，适合函数嵌套调用时都需要锁。

```python
lock = threading.RLock()
```

一般先学 `Lock`，遇到嵌套锁再用 `RLock`。

---

### 5. Event：线程间发信号

常用于通知线程停止。

```python
stop_event = threading.Event()

def worker():
    while not stop_event.is_set():
        print("working")

t = threading.Thread(target=worker)
t.start()

stop_event.set()
t.join()
```

比用全局变量更干净。

---

### 6. Condition：等待某个条件成立

适合“生产者-消费者”这类场景，但实际项目里更常用 `queue.Queue`。

---

### 7. Semaphore：限制并发数量

比如最多同时 3 个线程访问资源：

```python
sem = threading.Semaphore(3)

def task():
    with sem:
        do_something()
```

---

### 8. Timer：延迟执行

```python
timer = threading.Timer(5, print, args=("hello",))
timer.start()
```

---

### 9. local：线程本地数据

每个线程有自己的变量副本。

```python
local_data = threading.local()
local_data.user = "Alice"
```

常见于 Web 框架、数据库连接上下文。

---

### 10. queue.Queue：线程安全队列

虽然它不在 `threading` 里，但和线程经常一起用。

```python
import queue

q = queue.Queue()

def worker():
    while True:
        item = q.get()
        try:
            print(item)
        finally:
            q.task_done()
```

---

最推荐掌握顺序：

```text
Thread → join → Lock → Event → Queue → Semaphore → GIL
```

一句话总结：

`threading` 的核心不是“怎么开线程”，而是**怎么安全地让多个线程协作**。
