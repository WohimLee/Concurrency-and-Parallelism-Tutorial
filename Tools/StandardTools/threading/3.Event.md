`threading.Event` 是 Python 线程同步里非常实用、也最容易理解的工具之一。

可以把它理解成：

> 一个线程安全的“信号灯”。

线程之间不直接通信，而是通过检查这个信号灯的状态来协作。

---

# 1. Event 解决什么问题

假设有两个线程：

```text
主线程
    ↓
工作线程
```

你希望：

```text
工作线程先等待
主线程准备好了再通知它开始
```

如果不用 Event，很多人会写：

```python
ready = False

while not ready:
    pass
```

问题：

* 浪费 CPU
* 线程不安全
* 写法丑

Event 就是专门干这个的。

---

# 2. Event 的内部模型

Event 内部其实只有一个状态：

```text
False  (未触发)
True   (已触发)
```

刚创建时：

```python
event = threading.Event()
```

状态：

```text
False
```

可以理解成：

```text
红灯
```

---

# 3. 最重要的四个方法

## set()

把状态设为 True

```python
event.set()
```

```text
False → True
```

理解：

```text
红灯 → 绿灯
```

---

## clear()

把状态设回 False

```python
event.clear()
```

```text
True → False
```

---

## is_set()

查看状态

```python
event.is_set()
```

返回：

```python
True
False
```

---

## wait()

等待状态变成 True

```python
event.wait()
```

如果已经是 True：

```python
立即返回
```

如果是 False：

```python
阻塞
```

直到别人调用：

```python
event.set()
```

---

# 4. 最经典例子：启动信号

```python
import threading
import time

event = threading.Event()

def worker():
    print("等待开始")

    event.wait()

    print("开始工作")

t = threading.Thread(target=worker)

t.start()

time.sleep(3)

print("发出开始信号")

event.set()
```

输出：

```text
等待开始
(停3秒)

发出开始信号
开始工作
```

流程：

```text
worker
  ↓
wait()
  ↓
阻塞

main
  ↓
set()
  ↓

worker恢复
```

---

# 5. Event 是广播机制

Lock 唤醒一个线程。

Event 可以同时唤醒所有等待线程。

例如：

```python
event = threading.Event()

for i in range(5):
    threading.Thread(target=worker).start()
```

五个线程都：

```python
event.wait()
```

此时：

```text
全部阻塞
```

当：

```python
event.set()
```

结果：

```text
5个线程一起被唤醒
```

这点非常重要。

---

# 6. wait(timeout)

可以设置超时。

```python
event.wait(timeout=5)
```

意思：

```text
最多等5秒
```

返回值：

```python
True
```

表示：

```text
等到了 set()
```

或者：

```python
False
```

表示：

```text
超时了
```

---

例子：

```python
result = event.wait(timeout=3)

if result:
    print("收到信号")
else:
    print("超时")
```

# 7. 最常见场景：优雅停止线程

这是生产环境最常用的用法。

很多人一开始会写：

```python
running = True

def worker():
    while running:
        do_work()
```

停止：

```python
running = False
```

虽然能用，但有问题：

* 全局变量
* 不够优雅
* 可读性差

更好的方式：

```python
stop_event = threading.Event()
```

---

工作线程：

```python
def worker():

    while not stop_event.is_set():

        print("working")

        time.sleep(1)

    print("退出")
```

---

主线程：

```python
time.sleep(5)

stop_event.set()
```

输出：

```text
working
working
working
working
working
退出
```

---

这是最经典模式：

```python
while not stop_event.is_set():
    ...
```

很多框架都这么写。

# 8. Producer-Consumer 中的通知

例如：

```text
消费者等待任务
生产者放入任务
通知消费者
```

```python
event.wait()
```

收到通知后：

```python
取任务
```

不过现代代码一般直接用：

```python
queue.Queue()
```

因为 Queue 已经内置同步。

---

# 9. clear() 的作用

Event 默认是“一次开启，永久开启”。

例如：

```python
event.set()
```

以后：

```python
event.wait()
```

全部立即返回。

---

如果想重新进入等待状态：

```python
event.clear()
```

例如：

```python
event.set()

event.clear()
```

状态：

```text
True → False
```

又变回等待模式。

---

# 10. Event 像什么

可以这样记：

| 对象        | 像什么 |
| --------- | --- |
| Lock      | 门锁  |
| Semaphore | 停车位 |
| Queue     | 管道  |
| Event     | 红绿灯 |

---

Event：

```text
红灯
 ↓
wait()

绿灯
 ↓
set()
```

# 11. 一个真实案例：暂停/继续线程

```python
import threading
import time

pause_event = threading.Event()

pause_event.set()
```

---

工作线程：

```python
def worker():

    while True:

        pause_event.wait()

        print("working")

        time.sleep(1)
```

---

暂停：

```python
pause_event.clear()
```

线程会卡在：

```python
wait()
```

---

继续：

```python
pause_event.set()
```

线程恢复。

---

这就是：

```text
暂停
继续
```

功能的标准实现。

---

# 12. Event vs Lock

很多初学者会混淆。

### Lock

解决：

```text
谁能访问资源
```

例如：

```python
count += 1
```

只能一个线程改。

---

### Event

解决：

```text
什么时候开始
什么时候停止
什么时候继续
```

例如：

```python
event.wait()
```

等通知。

---

所以：

```text
Lock = 互斥
Event = 通知
```

这是最本质区别。

---

# 13. 实战中最值得掌握的两个模式

### 模式1：线程停止

```python
stop_event = threading.Event()

while not stop_event.is_set():
    work()

stop_event.set()
```

这是最常见的。

---

### 模式2：线程等待启动

```python
start_event = threading.Event()

start_event.wait()

do_work()
```

主线程：

```python
start_event.set()
```

所有工作线程同时开始。

---

如果你以后看源码（例如 `watchdog`、`uvicorn`、`gunicorn`、很多爬虫框架），会发现 `Event` 的使用场景大概有 80% 都是在做：

```python
stop_event = threading.Event()
while not stop_event.is_set():
    ...
```

它几乎已经成为 Python 多线程里“优雅关闭线程”的标准写法。
