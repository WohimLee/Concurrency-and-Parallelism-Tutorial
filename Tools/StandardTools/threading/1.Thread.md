## Thread 是什么

`threading.Thread` 是 Python 中最基础的线程对象。

一个进程（Process）里可以有多个线程（Thread）：

```text
Process
├── Thread-1
├── Thread-2
└── Thread-3
```

这些线程：

* 共享同一个进程的内存
* 可以访问相同的全局变量
* 可以同时等待 I/O
* 会受到 GIL 限制（CPython）

导入：

```python
import threading
```

---

# 一、最简单的创建方式

## target 方式

```python
import threading

def worker():
    print("working")

t = threading.Thread(target=worker)

t.start()
t.join()
```

执行流程：

```text
主线程
│
├─ 创建 Thread 对象
├─ start()
│
└─ worker() 在新线程执行
```

# 二、Thread 的构造函数

常见参数：

```python
Thread(
    group=None,
    target=None,
    name=None,
    args=(),
    kwargs={},
    daemon=None
)
```

---

## target

指定线程执行的函数

```python
def task():
    pass

t = threading.Thread(target=task)
```

---

## args

位置参数

```python
def hello(name, age):
    print(name, age)

t = threading.Thread(
    target=hello,
    args=("Tom", 18)
)
```

等价于：

```python
hello("Tom", 18)
```

---

## kwargs

关键字参数

```python
def hello(name, age):
    print(name, age)

t = threading.Thread(
    target=hello,
    kwargs={
        "name": "Tom",
        "age": 18
    }
)
```

---

## name

线程名字

```python
t = threading.Thread(
    target=task,
    name="worker-1"
)
```

查看：

```python
print(t.name)
```

输出：

```text
worker-1
```

---

## daemon

守护线程

```python
t = threading.Thread(
    target=task,
```

# 三、start()

这是最重要的方法。

```python
t.start()
```

作用：

```text
创建真正的操作系统线程
调用 run()
执行 target
```

例如：

```python
import threading

def work():
    print("thread running")

t = threading.Thread(target=work)

t.start()
```

输出：

```text
thread running
```

---

## 不要直接调用 run()

很多人容易写：

```python
t.run()
```

这不是启动线程。

只是普通函数调用：

```text
主线程
 └─ run()
      └─ work()
```

没有新线程产生。

---

正确：

```python
t.start()
```

---

# 四、join()

等待线程结束。

```python
t.join()
```

例如：

```python
import threading
import time

def work():
    time.sleep(3)
    print("done")

t = threading.Thread(target=work)

t.start()

print("waiting")

t.join()

print("finished")
```

输出：

```text
waiting
done
finished
```

---

## join(timeout)

最多等待多久

```python
t.join(timeout=2)
```

2 秒后继续执行。

---

例如：

```python
def work():
    time.sleep(10)

t.start()

t.join(timeout=2)

print("continue")
```

不会等满 10 秒。

# 八、守护线程 daemon

默认：

```python
daemon=False
```

意思：

```text
主线程退出
仍然等待子线程结束
```

例如：

```python
import threading
import time

def work():
    time.sleep(100)

t = threading.Thread(target=work)

t.start()

print("main end")
```

程序不会退出。

---

## daemon=True

```python
t = threading.Thread(
    target=work,
    daemon=True
)
```

主线程结束：

```text
整个进程直接退出
```

守护线程被强制终止。

---

典型用途：

```text
日志线程
监控线程
心跳线程
缓存刷新线程
```

# 九、继承 Thread

除了 target 方式，也可以继承。

```python
class Worker(threading.Thread):

    def run(self):
        print("working")
```

启动：

```python
w = Worker()

w.start()
```

执行流程：

```text
start()
   ↓
run()
```

---

带参数：

```python
class Worker(threading.Thread):

    def __init__(self, name):
        super().__init__()
        self.name = name

    def run(self):
        print(self.name)
```

# 十、线程异常

线程里的异常不会自动传回主线程。

```python
def work():
    1 / 0

t = threading.Thread(target=work)

t.start()
```

会打印：

```text
Exception in thread Thread-1
```

但主线程继续运行。

---

通常：

```python
try:
    ...
except Exception:
    ...
```

在线程内部处理。

# 十一、线程返回值问题

Thread 本身没有返回值。

不能：

```python
result = t.start()
```

因为：

```python
start() -> None
```

---

常见方案：

### 方案1：共享变量

```python
result = {}

def work():
    result["data"] = 123
```

---

### 方案2：Queue

```python
from queue import Queue

q = Queue()

def work():
    q.put(123)

t.start()
t.join()

print(q.get())
```

---

### 方案3：推荐

使用标准库：

```python
from concurrent.futures import ThreadPoolExecutor
```

它天然支持返回值：

```python
with ThreadPoolExecutor() as pool:
    future = pool.submit(work)

    print(future.result())
```

# 十二、实际项目最常见写法

### 后台任务

```python
threading.Thread(
    target=sync_data,
    daemon=True
).start()
```

---

### 多个下载任务

```python
threads = []

for url in urls:
    t = threading.Thread(
        target=download,
        args=(url,)
    )
    t.start()
    threads.append(t)

for t in threads:
    t.join()
```

---

### Worker + Queue

```python
while True:
    task = q.get()

    try:
        process(task)
    finally:
        q.task_done()
```

这是很多爬虫、任务系统、日志系统的基础模式。

如果从“面试/工程实践”的角度看，关于 `Thread` 真正必须吃透的是：

1. `start()` 和 `run()` 的区别
2. `join()` 的作用
3. `daemon` 的作用
4. `current_thread()`
5. `is_alive()`
6. 为什么线程共享内存
7. 为什么共享内存会产生竞态条件（从而引出 `Lock`）
8. 为什么 Python 线程受 GIL 影响

这几项加起来基本覆盖了 `threading.Thread` 80% 以上的实际使用场景。
